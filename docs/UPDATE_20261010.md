# 相对已上传 r99 的版本比较

GitHub旧版是2026-10-08上传的 `4fbe34fbe5dcfbfdb232bfe5406dfadd4efff1d6`，源码24文件，入口CloseGuardPlanner。当前导出候选是r43，源码34文件，入口UnifiedPlanner。原GitHub的r99源码、ZIP、130场记录和根目录stack保留；本次将新候选放在 `candidates/r43/`，没有将其标为通过晋级。

|---|---|---|---|
| 原DEV100+REG30 | 107到达/7碰撞/16超时 | 115到达/3碰撞/12超时 | 净增8到达、净减4碰撞和4超时 |
| 不涉及目标排序的123场 | 107到达/7碰撞/9超时 | 114到达/3碰撞/6超时 | 排除7场协议差异后的结果 |

| r43合计230场 | 不适用 | 199到达/8碰撞/23超时 | 追加开发集，不是封存测试集 |
| 原130逐场时延通过 | 130/130 | 72/130 | 不能称性能优化或实时合格 |
| 追加100时延通过 | 不适用 | 56/100 | 仍有44场未过 |

相对r99保留103/107个成功，新增12个到达，丢失4个成功。新增碰撞 `7_916_merge_921`，其余3个成功损失为 `1346cutin71`、`highway_merge_2_1_141`、`highway_merge_2_2_265`，当前为超时。r99的7个碰撞中5个恢复到达，但这不能抵消新碰撞。逐场结果和源码定义差异见 [r99_vs_r43.json](r99_vs_r43.json)。

输入范围：两版原130名单与原始输入文件SHA256一致。r99对反序目标框有隐式处理，而r43的规划器严格拒绝非法目标，回放协议显式排序7场的两轴边界并记录修正；XML未改变。7场中只有 `highway_merge_3_1_86` 从超时变到达，不能将这1场无条件称纯算法收益。其余6场仍超时。额外100同样使用明确的内存归一目标协议，其名单与原130/HOLD排除身份在run中保留；HOLD内容未包含。

## 代码中确实新增的能力

24个旧文件中17保持、7修改，另外增加10个文件。W1、当前观测锚定、覆盖预测、基础几何、预算尾部ETA、Numba基础优化等已在r99中存在，本次没有把它们重复算新增。

| 改动 | r99行为与r43行为 | 证据与边界 |
|---|---|---|
| 统一主/恢复/续行评估 | 原主规划按名义轨迹评估再由两秒guard覆写；当前候选在同一ExecutionEvaluator中推演，再单一提交ExecutionDecision | 新onsite_unified、candidates、unified_evaluation、decision_record；同一候选跨family评估一致，保存动作/下一状态对账 |
| 执行动力学契约 | 显式按官方停止修正、jerk、转角速率、幅值、旧速旧航向Euler和三位舍入推演 | 新replay_contract及修改native_execution/control；合成两种dt逐步对照，保存反馈 |
| 目标与对象保留 | 目标形状/有限值/顺序显式校验；当前圆近似重叠只作诊断，不删除对象后续占用 | 新goal_contract、修改arbiter/onsite_replay/close_guard；不将无检查称安全 |
| 完整车身道路门 | 使用地图车道联合、经语义核验的共享边界与车身角点；缺地图为unknown，回图后任何再外伸单列 | 新road_boundary/shared_border；二秒采样前缀是有限证据，不是完整未来或交通法规证书 |
| 路线连接/连续横移 | 消失车道不能横跳当纵向拓扑；连续横移缺几何/折返时合成连续路线并保全部图边承诺 | 修改route、新compound_route；r43对冻结r26只14_14有驾驶变化 |
| 仲裁与证据 | 实际目标入框与ETA分开；buffer不足与车身contact分开；失解时显式风险动作与对象/分支/时间 | 统一评估和道路门，不把有限生成集失解称物理无解 |

## 已独立验证的局部路线修复

r26→r43只改统一入口接入和compound_route，其余32源文件保持。两版230场中229场动作/状态逐值等价，仅 `14_14_left_straight_in_adjacent_38` 从r26的22.4秒出界变r43的12.0秒到达，回图后再外伸消失；无新增碰撞、成功损失、道路退化、异常或执行失配。初始回图0.7→0.9秒，未声称所有指标更好。

这与“相对r99是否晋级”是不同判据：r26已有的4成功损失和7_916新增碰撞仍未修好。r43相对r26路线收益通过，不代表相对r99整体通过。完整证据见 [full230_review.json](../candidates/r43/analysis/route_coverage_r43/full230_review.json)。

实际道路增长还在4场：`12_60`、`14_123`、`8_282`、`18_29`。前三场官方回放结局为到达，仍列道路问题；18_29为超时。地图增长不自动等于法律违规，采样检查不冒充连续安全。

## 本次没有计为完成收益的实验

r42的11_57/15_31/7_916恢复到达，但整版道路退化；r52的20_46恢复到达22.1秒，却恶化8_282道路；r54到达更早但外伸更早更大；r61解除3_1_301部分停车但仍超时；r62仅固定帧诊断，缩短横移存在新横向包络问题。以上都未进入34文件r43源码，局部反事实与闭环证据不作为已晋级优化。

已完成31场未到达只读归因：6已观测交通预测/恢复耦合、2终帧首次可见/起步能力；23超时分13持续推进不足、5高速刹停未再起步、1低速停走、3路线不穿目标盒、1占用道路恢复耦合。31场4968个下一状态对账0误差。22/23超时有可用前缀，不能统一归为预测无解，完整表见 [REPORT.md](../candidates/r43/analysis/nonarrival_attribution_r59/v2/REPORT.md)。
